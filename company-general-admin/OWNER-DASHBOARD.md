# Platform owner desktop 1.1.0+4

The live server reports platformOwner only for the explicitly configured owner user and company, using the separate company access-code session. Ordinary company sessions keep the existing company interface. Revoked owner memberships are checked on every owner request.

The owner interface contains date-filtered confirmed deposits (credit entries counted once), separate approved admin collections, current savings, expected active schedules, advance recognition due today, 24-hour deposits, new accounts, and platform counts. Directories cover admins, registered accounts, companies, communities and groups with search, pagination and person drill-downs. Admin ranking is current on-track client percentage, followed by approved collections in the selected period. Current schedules and snapshots do not reconstruct historical membership changes. Person membership detail lists are limited to 100 rows and labeled.

Company tools remain accessible for existing scoped messaging, approvals, staff and settings. Owner monitoring itself is read-only; it never enrolls clients or moves records into a company.

Temporary access code: Kibbisave. The backend binds it to the existing authorized owner account; it is not compiled into the executable.
